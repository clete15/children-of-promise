PAS Storage Check

Answers whether the PAS worksheets are actually on the server, and what this particular browser is holding. This page only reads. It never saves, never uploads and never deletes, so it is safe to open on any machine without risking whatever is stored there.

Deliberately does not load pas-store.js. That script uploads a browser's copy on load, which is the one thing we do not want happening by accident while we work out where a completed assessment went.

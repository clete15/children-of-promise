🖨️ Handouts

Handbooks →

Printable sheets for teachers, families and the monitoring folder. Open one and use its Print button — choose Save as PDF in the print dialog if you need a file to email or file. Each sheet is laid out for paper, so what prints is what was designed.

They are kept as living pages rather than saved PDF files on purpose: there is one copy of each, it is always the current one, and nobody has to wonder whether the PDF in their downloads folder is still right.
